# 多页面筛选范围编辑设计

## 背景与目标

现有 `@页面` 只传递环境、页面类型和页面 ID，卡片预览通过 `--with-default-filters` 使用页面默认筛选。第二阶段需要让用户在发送消息前查看并调整每个页面 chip 的数据范围，并确保 Agent 后续查询使用该范围。

本阶段目标：

- 每个页面 chip 展示来自页面筛选器的摘要，例如时间、区域。
- 点击 chip 可查看和调整该页面的筛选值。
- 候选项来自看板上对应筛选器的枚举值，不允许客户端凭空构造选项。
- 保存页面原有筛选器联动规则，编辑后按原规则刷新可用选项。
- 将调整后的值准确传入对应页面的卡片查询，不影响其他页面。
- Agent 能读到各页面范围摘要，并通过稳定范围句柄重复查询同一快照。

## 非目标

- 不默认把一张页面的筛选值传播到其他页面。
- 不实现跨页面字段映射或统一筛选。
- 不允许 Agent 自行拼接底层筛选器配置。
- 不改变现有环境鉴权、只读查询和资产引用安全边界。

## 核心模型

### 页面范围

每个被引用页面拥有独立的 `scopeId`，对应一份不可变范围快照。快照包含：

- 环境、页面 ID、页面名称。
- 页面筛选器的稳定 ID、名称、类型和原始配置。
- 筛选器当前有效值及其显示文本。
- 筛选器之间的原始联动规则。
- 卡片与筛选器的适用关系，以及卡片自身查询上下文。
- 范围来源：页面默认、当前页面状态或用户编辑。
- 快照版本和创建时间。

草稿中的编辑生成新版本；已提交或已经开始分析的快照不被后续编辑修改。

### 范围集合

一条消息中的全部页面引用组成一个范围集合。Host 保存完整快照，模型上下文只包含每页的 `scopeId`、页面身份、筛选摘要和必要警告。页面之间没有隐式筛选继承。

## 数据流

1. 用户在输入框选择页面后，Client 通过 Host RPC 获取该页面的筛选器定义、默认值、枚举选项和联动规则。
2. chip 展示筛选摘要；无法读取时明确显示“使用页面默认筛选”或读取失败状态，不能伪造空范围。
3. 用户打开范围编辑器后，只能使用该筛选器合法的枚举值。修改联动上游筛选器后，Client 请求 Host 按原始联动规则计算下游选项；失效的下游值被清除并显示变化。
4. 用户确认后，Host 校验筛选器 ID、值、类型和联动约束，在同一 `scopeId` 上保存新草稿修订并返回最新摘要。DSH chip 标签是插入时缓存，编辑后的最新摘要显示在编辑器中。
5. 提交消息时，页面引用与 `scopeId` 一起解析。Host 注入紧凑范围上下文，不把完整定义交给模型。
6. Agent 使用 `scopeId + cardId` 查询。Host 校验二者归属，将快照转换为 `guancli` 的页面卡片查询参数，保证同一快照的重复查询一致。

## 筛选与联动语义

- 页面原始配置是筛选器结构和联动关系的唯一事实来源。
- 枚举值必须从对应筛选器或其合法联动查询结果取得。
- 不修改原页面的保存配置；编辑只影响本次分析快照。
- 卡片只接收原本适用于它的页面筛选器，不能把全部页面筛选器无差别施加到每张卡片。
- 对不支持编辑、无法获取枚举或联动计算失败的筛选器保持只读，并说明原因。
- 时间宏和动态值保留其语义及求值上下文；不能把显示文本当作查询值。

## 接口方向

Client RPC 增加页面范围读取、联动选项解析和草稿校验/保存能力。草稿、会话和快照均有大小、数量与生命周期限制，RPC 继续使用本机同源约束。

`guancli_card_preview` 增加基于 `scopeId` 的查询方式。旧参数方式可暂时保留用于兼容，但模型使用约定优先引导到范围查询；同一调用不得同时提供两套可能冲突的范围来源。

## 上下文与回答约束

模型上下文包含每个页面的简短范围摘要，并明确：

- 各页面范围独立。
- 查询必须携带对应 `scopeId`。
- 跨页面比较前检查时间、区域、组织等范围是否一致。
- 范围读取或应用失败时不得声称已按用户选择分析。

## 错误处理

- 页面无筛选器：显示“无页面筛选器”，仍可使用页面默认上下文。
- 筛选器元数据读取失败：chip 显示失败状态，不开放伪造编辑。
- 枚举或联动失败：保留已选合法值，相关控件只读并显示错误。
- 快照过期或不存在：要求重新读取页面范围，不回退到另一组筛选条件。
- `scopeId` 与卡片或页面不匹配：拒绝查询。
- 底层 CLI 不支持所需参数：明确报告能力缺失，不静默退回默认筛选。

## 验证

- 单元测试覆盖摘要生成、快照不可变性、枚举校验、联动失效值清理和跨页面隔离。
- Host 测试覆盖 RPC 安全、范围归属、模型上下文和查询参数转换。
- Client 测试覆盖 chip 摘要、编辑器选项来源、编辑交互和失败状态。
- CLI 测试覆盖筛选值及页面上下文的准确传递。
- 使用真实看板验证：修改时间与区域、触发联动、预览受影响卡片、确认未受影响卡片及其他页面保持原范围。
